# 유튜브 트렌드 분석 대시보드

HTML 파일을 브라우저에서 열면 예시 데이터를 볼 수 있습니다. YouTube API 데이터가 필요하면 화면의 **YouTube API** 버튼을 눌러 API 키를 입력하세요. 입력한 키는 저장되지 않습니다.

> 이 프로젝트는 정적 웹페이지라서 YouTube API 키를 브라우저에서 완전히 비밀로 유지할 수 없습니다. API 요청 시 브라우저 네트워크 도구에 키가 노출될 수 있으므로 Google Cloud에서 HTTP referrer와 YouTube Data API로 키를 제한하세요. 키를 진짜 비밀로 유지해야 한다면 서버 측 프록시를 사용해야 합니다.

개인 사진(`photo.jpg`)은 공개 저장소에 포함하지 않으며, 대시보드에서 사진을 업로드해 로컬에서 사용할 수 있습니다. 이름과 학번도 기본값은 비워 두었습니다.
